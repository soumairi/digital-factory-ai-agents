# Engineering Principles

Applies to all future agent roles and consuming projects.

- Prefer simple, readable, modular designs with explicit responsibilities.
- Work only within the authorized scope. Keep changes focused and reviewable.
- Keep generic rules in the foundation, reusable technology rules in stack profiles, and single-project rules in the project layer.
- Avoid unnecessary abstractions, frameworks, dependencies, and configuration.
- Inspect existing context before changing it; preserve unrelated work.
- State assumptions and resolve material uncertainty before dependent work.
- Validate changes in proportion to their impact. Report evidence and distinguish completed checks from proposed checks.
- Treat security as part of design and implementation, not an optional final activity.
- Keep definitions independent of a model, vendor, or runtime; future adapters must preserve shared controls.
